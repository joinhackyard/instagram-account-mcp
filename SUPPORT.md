# Getting help

1. Run `npx @joinhackyard/instagram-account-mcp doctor`. It checks Node, the Meta app, account sign-in, the media host and ffmpeg, and tells you what to fix.
2. Read the README sections [Install](README.md#install) and [Things Meta decides](README.md#things-meta-decides-worth-knowing). Most problems are Meta app setup (redirect URI, permissions, tester roles), an Instagram account that is personal or not linked to a Facebook Page, or a media link Meta cannot reach.
3. Ask in [Discussions](https://github.com/joinhackyard/instagram-account-mcp/discussions).
4. Found a bug? [Open an issue](https://github.com/joinhackyard/instagram-account-mcp/issues/new/choose) and include the `doctor` output.
